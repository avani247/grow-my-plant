# Grow My Plant – Focus Timer

Single-page Pomodoro-style timer with glassmorphism styling and plant growth feedback.

## Local development

Open `index.html` in your browser or serve the directory with any static file server (for example `npx serve .`).

## Committing changes to GitHub

1. Verify the files you modified: `git status`.
2. Stage the updates you want to include in the commit: `git add <file>` or `git add .` to stage everything.
3. Review the staged diff to confirm the changes: `git diff --staged`.
4. Create a commit with a clear message: `git commit -m "Describe your change"`.
5. Push the commit to GitHub (replace `main` with your branch name if different): `git push origin main`.

## Deploying to GitHub Pages

1. Ensure your working branch is named `main` (this repository now uses `main` as the default branch).
2. Push the project to GitHub: `git push origin main`.
3. In your GitHub repository settings, enable GitHub Pages and choose the **Deploy from a branch** option with the `main` branch and `/ (root)` folder.
4. Save the settings—GitHub Pages will publish the site at the URL shown in the Pages dashboard.

The assets folder includes placeholders for adding your own ambient audio files when you're ready.
